# Raja Thrifts — Logo pack

**The mark:** a gold crown ("Raja" means king) sitting over a low-top sneaker (imported thrift footwear),
on a deep navy tile. It says *premium footwear, fit for a king, at thrift prices*.

## Which file to use

| Where | File |
|---|---|
| Instagram / Facebook / WhatsApp / TikTok profile picture | `png/raja-thrifts-profile-picture-1080.png` |
| Website header, invoices, documents (white background) | `png/raja-thrifts-logo-horizontal-light@4x.png` or `svg/…-horizontal-light.svg` |
| Dark / navy backgrounds, videos, stories | `png/raja-thrifts-logo-horizontal-dark@4x.png` |
| Square posts, packaging stickers, shop sign | `png/raja-thrifts-logo-stacked-on-white.png` / `-on-navy.png` |
| Transparent stacked logo | `png/raja-thrifts-logo-stacked-light.png` / `-dark.png` |
| App icon / small spaces | `png/raja-thrifts-icon-1024.png` |
| Link previews, Facebook cover, banners | `png/raja-thrifts-social-banner-1200x630.png` |
| Printing (any size, stays sharp) | anything in `svg/` |

`light` = for light backgrounds (navy text). `dark` = for dark backgrounds (white text).

## Colours

| Name | Hex |
|---|---|
| Royal navy | `#1B2550` (tile gradient `#25347C` → `#0C1230`) |
| Crown gold | `#D4A63A` (highlight `#F2D27C`) |
| Wordmark gold on white | `#B8861F` |
| Wordmark gold on navy | `#E3B64D` |
| White | `#FFFFFF` |

**Font:** Plus Jakarta Sans ExtraBold (wordmark), Bold (tagline). Free on Google Fonts.
Text in the SVG files is converted to outlines, so the font does not need to be installed.

## Do / don't
- Keep clear space around the logo at least the height of the crown.
- Don't stretch, recolour the crown, or place the light version on dark photos.
- Smallest size: icon 24 px, horizontal logo 120 px wide.
