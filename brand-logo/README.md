# Raja Thrifts: logo pack

Your badge design, rebuilt as a clean vector so it stays sharp at any size:
a royal crown over the collegiate **RAJA** wordmark, **THRIFTS** in gold, a sneaker,
and the motto *Quality · Style · Sustainability*.

The sneaker is a generic high-top with a small gold crown on its side panel. It replaces the
original sneaker, which carried the Nike swoosh: putting another company's trademark in your
logo could get your pages or ads taken down.

## Which file to use

| Where | File |
|---|---|
| Instagram / Facebook / WhatsApp / TikTok profile picture | `png/raja-thrifts-profile-picture-1080.png` |
| Stickers, packaging, posts, shop sign (main logo) | `png/raja-thrifts-badge-2000.png` (transparent) or `svg/raja-thrifts-badge.svg` |
| Website header, invoices, letterheads (white background) | `png/raja-thrifts-logo-horizontal-light.png` |
| Dark backgrounds, video intros, stories | `png/raja-thrifts-logo-horizontal-dark.png` |
| Text-only logo | `png/raja-thrifts-wordmark-light.png` / `-dark.png` |
| Small spaces, app icon | `png/raja-thrifts-icon-1024.png` (crown + sneaker, no text) |
| Favicon / tiny sizes | `png/raja-thrifts-favicon-512.png` (crown only) |
| Facebook cover, link previews, banners | `png/raja-thrifts-social-banner-1200x630.png` |
| Printing at any size | anything in `svg/` |

`light` is for light backgrounds and `dark` is for dark backgrounds.
When the badge is smaller than about 120 px, use the icon instead: the small text gets hard to read.

## Fonts
- **RAJA:** Graduate (collegiate). **THRIFTS** and the motto: Cinzel Bold. Both are free on Google Fonts.
- Text in the SVG and PNG files is already converted to outlines, so you don't need to install the fonts.
